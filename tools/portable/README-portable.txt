ДЭ-2027 — портативная платформа подготовки к демоэкзамену

Запуск:
  Дважды щёлкните DE-2027.exe.
  Откроется браузер с адресом http://127.0.0.1:8100.

Что внутри:
  app\        Laravel-приложение: уроки, лабораторные, проект, капстоун, админка
  runtime\    встроенный PHP 8.5 и расширения
  app\database\database.sqlite — база данных

Аккаунты:
  Администратор: admin / Admin2027!
  Студент:       student / Student2027!

Важно:
  - Папку можно переносить целиком, но не переименовывайте app и runtime.
  - Если порт 8100 занят, лаунчер возьмёт 8101–8110.
  - Чтобы остановить сервер, закройте окно лаунчера.
  - Логи: app\storage\logs\portable-serve.log
  - Это локальная версия: данные хранятся в SQLite на этом компьютере.
  - Глубокая проверка проекта запускает код выбранного проекта. Используйте её только для своих проектов.
