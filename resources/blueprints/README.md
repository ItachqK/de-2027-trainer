# @@PROJECT@@

Информационная система для @@PURPOSE@@. Учебный проект под демонстрационный экзамен
по специальности **09.02.07 Информационные системы и программирование**,

стили и один скрипт лежат в `public/`.

## Что умеет

| Страница | Маршрут | Доступ |
|---|---|---|
| Главная | `/` | всем |
| Регистрация | `/register` | гость |
| Вход | `/login` | гость |
| Мои заявки | `/bookings` | авторизован |
| Новая заявка | `/bookings/create` | авторизован |
| Админка заявок | `/admin/bookings` | роль `admin` |

- Регистрация: ФИО, логин, телефон, почта, пароль. Логин и почта уникальны.
- Заявка: «@@OBJECT@@» из списка, @@DATE_LABEL@@, способ оплаты, комментарий.
- Два способа оплаты: @@PAY1@@ и @@PAY2@@.
- Три статуса: «@@STATUS_NEW@@» → «@@STATUS_ASSIGNED@@» → «@@STATUS_DONE@@».
  Переход только вперёд, шаг назад и прыжок через статус запрещены.
- Отзыв: @@REVIEW@@, один раз и только после статуса «@@STATUS_DONE@@».
- Админка: фильтр по статусу, поиск по логину и названию, смена статуса.

## Установка

```bash
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed
php artisan serve
```

Откройте http://127.0.0.1:8000.

На Windows файл базы создаётся так:

```powershell
New-Item database\database.sqlite -ItemType File -Force
```
